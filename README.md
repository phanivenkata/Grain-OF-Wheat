# A Grain of Wheat Christian Ministry in Boston

A modern church landing page built with HTML, CSS, and JavaScript.

## Local preview

Open the folder in a browser, or run:

```bash
cd /Users/phanikoli/church-site
python3 -m http.server 8000
```

Then visit:

http://localhost:8000

## Deployment options

### Option 1: Netlify
1. Push this folder to GitHub.
2. Sign in to Netlify and choose "Add new site" > "Import an existing project".
3. Connect the repository.
4. Set the publish directory to the project root (or the folder containing the HTML files).
5. Deploy.

### Option 2: GitHub Pages
1. Push to a GitHub repository.
2. Open the repository settings.
3. Go to Pages.
4. Select the main branch and root folder.
5. Save and wait for deployment.

### Option 3: Vercel
1. Import the repository to Vercel.
2. Keep the default static site settings.
3. Deploy.
